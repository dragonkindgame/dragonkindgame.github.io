Login code not arriving?

  • Check Spam, Promotions and filtered folders.
  • Use a normal inbox rather than a disposable email address.
  • Wait a few minutes before requesting another code.
  • Keep only the newest code; an older one may have expired.

MOST ASKED

Can you force a black dragon?

No guaranteed method has been confirmed. Players report a battery-level pattern, but it remains a community theory rather than an official answer key.

Confirmed
Black is a rare dragon color in the source world, and Dragonkind can produce black-dragon results.
Player-reported

Not proven
No official matching formula or set of choices guarantees black, blue or any named dragon.

DIRECT ANSWERS

Dragonkind game FAQ

Where do I play the official Dragonkind game?

Open dragonkind.com. It uses email-based entry and sends a one-time login code.

Why is my Dragonkind login code not arriving?

Check Spam and Promotions, use a normal inbox, wait a few minutes and request a fresh code. Use the newest code received.

Is there a guaranteed Dragonkind answer key?

No. Repeating the same route does not guarantee the same bond, and no official list of choices guarantees a particular dragon.

How do I get a black dragon?

No official method is confirmed. The 76%–90% battery claim is player-reported and should be treated as an experiment, not a promise.

When can I manifest a signet?

The supplied companion guides report May 2027 as the announced signet stage. A current bond result does not include a playable signet test.
